# Graph-Greener

Graph-Greener — Python tool to paint your GitHub contribution graph green with backdated commits.

> Script lives in `Graph-Greener-main/main.py`.

## Getting Started
```bash
cd Graph-Greener-main
python main.py
```

Requires Git configured locally and a GitHub repo remote to push the generated commits.

## Tech
- Python 3 (stdlib + git CLI)
